# Система управління бібліотекою

## Опис
Модульна система для автоматизації роботи бібліотеки, написана на Python. Реалізує облік книг, реєстрацію читачів та автоматичні email-сповіщення за допомогою патерну Observer. Центральним ядром системи є клас Library (Singleton).

## Встановлення та запуск
1. Клонувати репозиторій: `git clone <посилання>`
2. Запустити головний файл: `python main.py`
3. Запуск тестів: `python -m unittest discover tests/`
